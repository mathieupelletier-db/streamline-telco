Lakebase Search — BM25 full-text search via the lakebase_text extension.

Extensions enabled: lakebase_text (0.1.1), lakebase_tokenizer, lakebase_vector (1.1.0).
Search uses the lakebase_bm25 access method with the tsvector_bm25_ops operator class, the
to_bm25query(tsvector, index_regclass) query builder, and the BM25 ranking operator <@>
(ascending sort; more-negative score = stronger match). This is native Lakebase Search, not
generic Postgres FTS.

Setup (app-owned search corpus over the synced read-only mirrors):
  -- Offer catalog
  CREATE TABLE public.offer_search AS SELECT offer_id, offer_name, offer_type, value_usd, description FROM public.offers;
  ALTER TABLE public.offer_search ADD COLUMN description_tsv tsvector
      GENERATED ALWAYS AS (to_tsvector('english', coalesce(description,''))) STORED;
  CREATE INDEX idx_offer_search_bm25 ON public.offer_search USING lakebase_bm25 (description_tsv tsvector_bm25_ops);
  -- Subscriber service history
  CREATE TABLE public.service_history_search AS
      SELECT subscriber_id, home_metro, plan_type, risk_band, churn_reason, service_summary FROM public.subscriber_position;
  ALTER TABLE public.service_history_search ADD COLUMN summary_tsv tsvector
      GENERATED ALWAYS AS (to_tsvector('english', coalesce(service_summary,''))) STORED;
  CREATE INDEX idx_service_history_bm25 ON public.service_history_search USING lakebase_bm25 (summary_tsv tsvector_bm25_ops);

Natural-language query: "one-time credit for a service outage or billing dispute"

Query A (BM25 over the offer catalog):
  SELECT offer_id, offer_name, offer_type, value_usd,
         description_tsv <@> to_bm25query(to_tsvector('english','one-time credit service outage billing dispute'),
                                          'idx_offer_search_bm25') AS bm25_score
  FROM public.offer_search
  ORDER BY bm25_score LIMIT 5;

Query B (BM25 over subscriber service history, joined to the recommended offer):
  SELECT s.subscriber_id, s.home_metro, s.risk_band, r.recommended_offer,
         s.summary_tsv <@> to_bm25query(to_tsvector('english','outage node billing dispute open ticket'),
                                        'idx_service_history_bm25') AS bm25_score,
         s.service_summary
  FROM public.service_history_search s
  JOIN public.retention_recommendations r ON s.subscriber_id = r.subscriber_id
  ORDER BY bm25_score LIMIT 5;

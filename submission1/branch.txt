DEVELOPMENT BRANCH — Lakebase (Autoscaling), project streamline-telco
=====================================================================

Branch name:        dev   (created off the production branch)
Parent branch:      production   (the "main" line)
Dev endpoint host:  ep-silent-block-e88gklku.database.centralus.azuredatabricks.net
Prod endpoint host: ep-fancy-frost-e8290smv.database.centralus.azuredatabricks.net

Branch model: Lakebase Autoscaling branches are copy-on-write from a point-in-time snapshot of
the source branch — the dev branch is an isolated, independently-writable copy of production's
data + schema. Work is done + validated on dev, then promoted (the validated DDL/data is applied)
to production.

Created with:
  databricks postgres create-branch projects/streamline-telco dev \
    --json '{"spec": {"source_branch": "projects/streamline-telco/branches/production", "no_expiry": true}}'

BRANCH CREATION CAPTURED IN CODE
--------------------------------
The dev-branch-off-main workflow is a first-class app artifact:
  app/scripts/lakebase_branch_workflow.sh
    create  -> create the dev branch off the MAIN (production) line (copy-on-write)
    apply   -> apply + validate a migration on the dev branch
    promote -> promote the validated migration to the main branch

Execution evidence: dev_branch_creation.json lists the live branches with their parent_branch,
showing `dev` and `dev-forecast` were created off `projects/streamline-telco/branches/production`
(the main line). The workflow script's `create` command was run against the live project to
produce this.
